# ConnText-Server

Backend server for [ConnText](https://github.com/Mx-Angel/ConnText-Docs), a self-hosted, privacy-focused communication platform.

## Tech Stack

- **Language:** TypeScript / Node.js
- **Framework:** Express.js
- **Database:** PostgreSQL
- **Auth:** OPAQUE (opaque-ke) + JWT
- **API Docs:** OpenAPI 3.2.0

## Prerequisites

- Node.js (LTS recommended, install via [nvm](https://github.com/nvm-sh/nvm))
- Docker & Docker Compose (for PostgreSQL)

## Documentation

Full project documentation, architecture decisions, and API contracts can be found in the [ConnText-Docs](https://github.com/Mx-Angel/ConnText-Docs) repository.
