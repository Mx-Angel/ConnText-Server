## Reporting of Security Vulnerabilities

Thank you for helping keeping this project secure, we appreciate non-public disclosure of security vulnerabilities and will do our best to handle them as quick as possible.

### Report a Vulnerability

We use GitHub's Private Vulnerability Reporting (PVR) to handle security related issues. **DO NOT OPEN A PUBLIC ISSUE FOR SECURITY BUGS**.

To report a vulnerability:

1. Navigate to the **Security and Quality** tab.
2. Click **Report a Vulnerability**.
3. Fill out the private disclosure form.

### Requirements for a Valid Report

- Please ensure the issue is reproducible on `main`.
- Please ensure a fully working, end-to-end reproducer is provided.
- Please ensure the reproducer is real-world and not simulated or abstracted.
- Please ensure the reproducer demonstrably violates a security boundary.

Note: Please understand that most of our maintainers are volunteers and al. While we will try to triage and fix issues in a timely manner, we cannot guarantee any fixed timeline for issue resolution.
